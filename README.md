# justchesschess

A minimal real-time browser chess site. Instant random matchmaking, no
friends/search, unique usernames, win/loss leaderboard only. 2D board first,
3D board later. Black UI.

## Project structure

- `server/` - Node.js and Socket.IO backend
- `client/` - React and Vite frontend

Authentication, matchmaking, game management, and database behavior will be
added in follow-up steps.
